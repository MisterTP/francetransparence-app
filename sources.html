Sources

Oui : les tuyaux existent pour l’Assemblée, le Sénat et le Parlement européen. Non : on ne reconstruit pas l’agrégateur. Registre machine : data/sources.json.

Votes — Assemblée nationale

  • Source juridique : scrutins publics XVIIe (ex. n° 519, censure Barnier).
  • Vote nommé : page « positions de vote » de chaque député (ex. Alma Dufour).
  • Miroir quotidien : NosParlementaires sur data.gouv — 8 434 scrutins, ~1,25 M votes individuels, CSV/JSON.
  • Légende humaine : Datan (décryptage, pas acte officiel).

Votes — Sénat

  • Fiches et dossiers : senat.fr + open data data.senat.fr.
  • Même dump NosParlementaires (onglet Sénat, 909 scrutins).

Votes — Parlement européen

  • Acte : XML roll-call du PE (doceo), votes nominatifs seulement.
  • Miroir exploitable : HowTheyVote.eu — export CSV members / votes / member_votes, API developers.
  • Limite : pas les votes à main levée. Un député européen se compare à la profession de liste 2024, pas à une circo législative.

Programmes et professions de foi

  • Législatives 2024 : Barodet XVIIe (PDF par département). Démo : Vallaud T2, Boccaletti T1, Dufour T2.
  • Programmes de liste (quand le recto-verso est trop court) : contrat NFP juin 2024, Ensemble 2024, circulaires RN/LR. La fiche doit le dire.
  • Européennes 2024 : programme-candidats.interieur.gouv.fr (souvent hors ligne hors campagne) + archive.org.
